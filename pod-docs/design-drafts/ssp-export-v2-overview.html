SSP export v2: an assessor-ready System Security Plan

The export follows NIST's own CUI SSP template outline and adds the sections 32 CFR 170.19 expects: an asset inventory by the five Level 2 categories, external service providers with a responsibility matrix, diagrams and CUI data flows, roles, document control, and per-objective detail. A pre-export lint shows what an assessor will catch, and a templates/ folder holds the official references.

1The exported document, v1 → v2

v1 (today)

  1. System characteristics
  2. Assessment summary (SPRS, Conditional, 180-day)
  3. Security requirements
  4. Plan of action and milestones

v2 (this plan)

  1. System identification + categorization, security officer, roles table
  2. System environment + topology and CUI data-flow narratives, embedded diagrams, hardware and software inventory reference
  3. CUI description · asset inventory (5 categories) · service providers and responsibility matrix
  4. Requirements: Implemented / Planned / Not applicable, planned implementation, N/A rationale
  5. Plan of action and milestones
  6. Record of changes (automatic on export) and approval signature lines
  7. Appendix A: assessment status (SPRS, Conditional, 180-day) · Appendix B: assessment objectives

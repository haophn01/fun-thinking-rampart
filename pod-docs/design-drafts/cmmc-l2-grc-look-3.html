Look C, refined: Inspection

Left: C as you picked it. Right: the same C palette with no new colors, plus the culture of inspection tools:

  • The SPRS score is read off a vernier caliper, with LSL 88 and USL 110 spec limits.
  • Status reads as a GO / NO GO gauge.
  • Sections carry ballooned characteristic numbers, as on an inspected drawing.
  • A GD&T-style feature control frame states the result.
  • Progress bars are graduated scales.
  • An inspection-report strip and a red inspector's stamp complete the page.

ABLACK OPS

Signature: the SPRS instrument dial, a −203 → 110 gauge with an orange notch at 88.

BFLIGHT LINE

Signature: the 320-cell objective matrix, every assessment objective as one lit cell.

CSpec Sheet

Light, precise and technical: an engineering drawing with hairline rules, numbered sections and signal-red callouts.

Signature: the dimension-line score ruler, which shows how far you are from 88 like a drawing measurement.

CInspection

The Spec Sheet run through the quality lab. Same paper, ink, red and blue. Readiness is measured like a part: read off a caliper, checked against spec limits, gauged GO / NO GO, ballooned and stamped.

Signature: the vernier caliper score. The slider sits at your score against the LSL 88 limit, and a feature control frame reads MEAS 72 · LSL 88 · OUT OF TOL.

# Idea: NIST SP 800-171 Rev 3 catalog

Status: parked

## The idea
Add the NIST SP 800-171 Rev 3 / 800-171A Rev 3 catalog next to Rev 2: 97 requirements with new numbering and organization-defined parameters. NIST publishes it as official OSCAL in `usnistgov/oscal-content`, so it can be imported directly. Add a Rev 2 → Rev 3 crosswalk view so a contractor can see what changes for them. The V1 data model is versioned by catalog for exactly this. From the research: [cmmc-l2-grc](../research/cmmc-l2-grc.md).

## Why it's on hold
CMMC Level 2 (32 CFR 170) is assessed against Rev 2. The SPRS point weights and the POA&M rules (the barred list and the 1-point limit) are written against Rev 2 IDs, and DoD has published no SPRS scoring for Rev 3. Plan `cmmc-l2-grc` builds on Rev 2.

## What would make it worth building
DoD announcing a move of CMMC / DFARS 7012 to Rev 3, ideally with scoring guidance, or a prime contractor asking for Rev 3 alignment.

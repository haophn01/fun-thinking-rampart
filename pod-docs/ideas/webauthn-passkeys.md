# Idea: WebAuthn / passkeys MFA

Status: parked

## The idea
Add phishing-resistant MFA with WebAuthn (passkeys, or security keys such as YubiKey) alongside TOTP, from plan security-hardening.

## Why it's on hold
TOTP comes first (security-hardening Q10). WebAuthn needs HTTPS and a stable origin, so it fits better once hosting is decided.

## What would make it worth building
Rampart is hosted, or an assessor or customer asks for phishing-resistant MFA.
